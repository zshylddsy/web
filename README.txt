钢琴社招新网站文件说明
1. jin-0120-work2.html：网站主页，包含社团简介、春季活动安排、图片轮播、视频、社员故事和在线报名。
2. club_intro.html：钢琴社活动介绍页。
3. assets/piano-club.jpg：原有带超链接的钢琴社图片（点击进入活动介绍页）。
4. assets/piano-meeting-1.jpg、assets/piano-meeting-2.jpg：新增轮播照片。
5. assets/piano-theme.mp3：背景音乐。
6. assets/piano-club-video.mp4：更新后的视频素材。

使用方法：保持 assets 文件夹与网页文件处于当前相对位置，双击 jin-0120-work2.html 即可打开主页。上传 GitHub 时请完整上传本文件夹。
在线报名表为前端演示表单，没有连接后台。
